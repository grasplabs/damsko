## In code

The times are variables in `lib/vars.stylex.ts`, which comes with every component: `motionVars` become `0s` when the person asks for reduced motion, so a part that would move, grow or fade is then simply there, and simply gone. The curves and the colour times are `duration` in `lib/tokens.stylex.ts`.

```bash
pnpm dlx shadcn@4.23.0 add @damsko/lib
```

### motionVars

Use `motionVars` for movement, size and fades: `ui` for something opening, `leave` for it going, `popup` for a menu or a list, `swap` for one state giving way to the next.

```tsx
import { duration } from "@grasp-os/ui/lib/tokens.stylex";
import { motionVars } from "@grasp-os/ui/lib/vars.stylex";

const styles = stylex.create({
  panel: {
    transitionProperty: "opacity, transform",
    transitionDuration: {
      default: motionVars.ui,
      ":is([data-ending-style])": motionVars.leave,
    },
    transitionTimingFunction: duration.ease,
  },
});
```

### duration

`duration.ease` and `duration.easeInOut` are the two curves. A colour easing under the pointer is not motion: it keeps `duration.hover`, and stays under reduced motion. A spinner or a progress bar that must keep a sign of life under reduced motion keeps a slow fade of its own.

```tsx
const styles = stylex.create({
  row: {
    transitionProperty: "background-color",
    transitionDuration: duration.hover,
    transitionTimingFunction: duration.ease,
  },
});
```
