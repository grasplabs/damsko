## Every icon

Import an icon by the name it has in Damsko, from `lib/icons`. The set holds what Damsko's own parts draw, and the shapes products share one meaning for, so "more actions" is the same drawing everywhere.

Two that are easy to mix up: `PencilOffIcon` (the pencil, struck through) marks what may be opened and read but not changed; `LockIcon` marks what cannot be opened at all.

## Any other drawing

A product needs drawings the set does not hold. It imports them from `@hugeicons/core-free-icons`, the package `lib/icons` draws from and which the CLI added to its `package.json` with the first component, by Hugeicons' own name, and draws them through `Icon`: nothing in Damsko changes. Only the drawings a page imports reach its bundle. A drawing that points along the line (an arrow, a chevron, send) is marked once where it is named, so it turns round in right-to-left text. In a workspace, the app that imports a drawing names the package too, at the catalog's version.

```tsx
import { directional, Icon } from "@grasp-os/ui/lib/icons";
import { ArrowRight03Icon, Briefcase01Icon } from "@hugeicons/core-free-icons";

const NextIcon = directional(ArrowRight03Icon);

<Icon icon={Briefcase01Icon} />
<Icon icon={NextIcon} />
```

A drawing that every product comes to share moves into the set, named by its shape.
