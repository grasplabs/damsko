## Basic usage

Enter or a comma adds what was typed; pasted words split on commas and lines. A value already there is refused, and the field says why.

<Stage path="tags-input/basic" label="Basic usage" />

## Suggestions

`suggestions` open as you type; anything else typed is added as it is.

<Stage path="tags-input/suggestions" label="Suggestions" />

## Many tags

They wrap onto more lines inside the field. `max` sets how many it takes.

<Stage path="tags-input/many" label="Many tags" />

## A wrong value

`validate` returns `true` for a right value, and `false` or the words that say why for a wrong one. A wrong value is kept, so it can be corrected, with a destructive edge, and a screen reader hears why after its words. Say under the field what is wrong, as any field does.

<Stage path="tags-input/invalid" label="A wrong value" />

## In a form

Each tag is sent under the Field's name, and a reset brings back the tags it started with. A Field that is out of use takes the field with it.

<Stage path="tags-input/form" label="In a form" />
