## Sizes

Four sizes in Geist Serif, from an opening title to a card's; two in the sans, a component's title and a section's inside it.

<Stage path="heading/sizes" label="Sizes" />

## Level and size

The level keeps the outline whole; each has a size by default, and `size` changes only the look.
