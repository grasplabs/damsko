## A run

Test Results is a Trace with a row that opens for the run. `TestResultsHeader` is the row's line: the flask, `TestResultsSummary` counting what ran and failed from `summary`, and `TestResultsDuration`. In red when a test failed, and then open at first. Each `Test` is a line with its mark, its name and its duration; a failed one with a `TestError` opens on the error, its `TestErrorMessage` and `TestErrorStack` on the code surface.

<Stage path="test-results/basic" label="A run" />

## Suites

Group tests by file: each `TestSuite` is a row of its own, its `TestSuiteName` the file and `TestSuiteStats` its counts, open at first when it failed. A skipped test says so in its name.

<Stage path="test-results/suites" label="Suites" />

## Every test passed

A run where every test passed stays closed until opened. `TestResultsProgress` shows how many passed as a bar.

<Stage path="test-results/passed" label="Every test passed" />
