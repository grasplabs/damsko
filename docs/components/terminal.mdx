## A command that ran

Terminal is a Trace with one row that opens. `TerminalTitle` is the row's line, the command as a sentence ("Ran pnpm build"); a press opens `TerminalContent` on what it printed, on the code surface.

<Stage path="terminal/basic" label="A command that ran" />

## Exit code

A command that exits with any code other than 0 failed: give its `TerminalHeader` `status="error"` and say so in the title.

<Stage path="terminal/error" label="Exit code" />

While `isStreaming`, the line runs without a `status`.

## Colours

The output's ANSI colours and marks are drawn in Damsko's syntax and status colours, as text; every other escape sequence is taken out. Without children it draws its own header: the title, `TerminalCopyButton`, which copies the words without their escape sequences, and `TerminalClearButton` when there is an `onClear`.

<Stage path="terminal/colours" label="Colours" />

## While it runs

The line runs and opens once the command prints. The output follows its end as it grows, until you scroll up; the line is said once when the command is done. `TerminalStatus` stands beside the line while it runs.
