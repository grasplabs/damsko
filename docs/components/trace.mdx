## Start with a pattern

Most of the time you want a pattern built on Trace: [Reasoning](/components/reasoning), [Tool](/components/tool), [Chain of thought](/components/chain-of-thought), [Sources](/components/sources), [Terminal](/components/terminal), [Stack trace](/components/stack-trace), [Test results](/components/test-results). Use Trace itself when none of them fits.

## Steps

`Trace` is a list of lines. A `TraceLine` straight inside it is a step: its first `TraceIcon` in a seat at its start, so the titles start at one edge, a quiet line of square pixels down from its mark to the next step's, its `TraceTitle` and a `TraceDescription`. A `TraceIcon` with nothing in it is the status mark.

<Stage path="trace/steps" label="Steps" />

## A row that opens

Put the `TraceLine` in a `TraceCollapsibleTrigger` and the detail in `TraceCollapsibleContent`: a quiet row, as wide as its line, its mark beside its title, its words muted until the pointer is on it or it is open, its chevron turning as it opens. The row's words stand on the column's edge, where the lines under it start; its fill under the pointer reaches past them. Rows open inside rows: here a commit opens on a line for each file it changed, and each file on its diff.

<Stage path="trace/commit" label="A row that opens" />

## A plan

When every step is known before the work starts, show them all from the start: the ones not begun are `pending`. The row's line holds the goal as its title and the progress as its description, and is `running` while the plan is worked through.

<Stage path="trace/plan" label="A plan" />

## A queue

What waits is a list of lines too: a row for each group, its line the count and what it holds, the list under it. A line still waiting is `pending`; one that is done says so in words before its title, for a screen reader, not by its tick alone.

<Stage path="trace/queue" label="A queue" />

## A subagent

Work handed to another agent is a run inside the run: one row, its line the run in the tense of its status, the model as its description. It opens on that agent's own tool calls as a `Trace`, what it returned as a Code block and what it found.

<Stage path="trace/subagent" label="A subagent" />

## While it works

A line is said once, when its status changes after it was drawn: when it finishes or fails. A line is never said for appearing. Press Next to finish the running step.

## When to use it

  of="trace"
  always={[
    "The steps an assistant takes: calling a tool, searching, reading, thinking, editing a file.",
    "A title in the tense of the status: Searching the web while running, Searched the web once done, Failed to search the web when it failed.",
    "A line in a trigger to make it open, or in a link or a dialog's trigger to make it go somewhere.",
  ]}
  never={[
    "A step a part built on Trace already names: use Tool for a call, Reasoning for thinking, Chain of thought for an answer's steps.",
    "The assistant's reply: use Message.",
    "A question for the person, such as approving a tool: use Confirmation, outside the Trace.",
  ]}
/>
