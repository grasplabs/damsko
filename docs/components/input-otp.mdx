## Basic usage

Six digits in two threes, as the code reads in its message.

<Stage path="input-otp/basic" live label="Basic usage" />

## Lengths

A four-digit PIN, or a longer code split so it is easier to copy.

<Stage path="input-otp/lengths" label="Lengths" />

## Sizes

36px squares in a form, 44px when the code is all a screen asks for.

<Stage path="input-otp/sizes" label="Sizes" />

## States

A code turned down, one shown to copy, and one out of use.

<Stage path="input-otp/states" label="States" />

## Every state

Hover is forced from its own CSS; the rest are props. The square typing goes to takes the focus edge only under real focus.

## When to use it

<Intent
  of="input-otp"
  always={[
    "A one-time code or a PIN, checked as soon as the last square fills.",
    "A label that says what the code is: Verification code, PIN.",
    "`onComplete` to check the code as soon as the last square fills.",
    "An error that says what to do next: Ask for a new one.",
  ]}
  never={[
    "One input per square: paste and autofill break.",
    "A password or a key that is not a code: use an Input.",
    "Colours or sizes set from outside: `style` takes layout only.",
  ]}
/>
