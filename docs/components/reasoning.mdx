## When it is done

Built as shadcn's Reasoning pattern is, on [Trace](/components/trace): `Reasoning` is a Trace with one row that opens, `ReasoningTrigger` its line. `ReasoningTrigger` says how long the assistant thought, from `duration` in seconds. A press opens `ReasoningContent`, the thoughts in Markdown, loaded the first time they show. The line is the original's thinking line: its words alone, no chevron and no mark; pass one as `ReasoningTrigger`'s children to show it.

<Stage path="reasoning/basic" label="When it is done" />

## While it thinks

With `isStreaming` the line runs (Trace's `status="running"`), says Thinking in the shimmer, and the thoughts open by themselves. A second after it ends the line settles into how long it thought, measured when no `duration` is given, and closes, unless the person opened or closed it meanwhile. Press Think to run it.
