## A conversation

A Bubble is as wide as its words, up to most of the line. The person's own messages stand at the end (`align="end"`) in the `muted` look; consecutive messages from one sender go in a `BubbleGroup`, closer together. In a chat, put each Bubble in a Message, which lays out the row: avatar, header, footer and side.

<Stage path="bubble/demo" label="A conversation" />

## Looks

`variant` sets the fill: `default` the action fill, `secondary` the quiet fill, `muted` the person's message, `tinted` a wash of the brand, `outline` the page with the one edge, `destructive` a failure, `ghost` no frame at all, across the whole row.

<Stage path="bubble/variants" label="Looks" />

## Sides

`align="start"` by default; `end` for the person's own. In a Message, set `align` on both.

## Replies as buttons

With `asChild`, BubbleContent draws the one button or link it is given with the Bubble's look: reached by Tab, named by its words, its fill a step down under a pointer.

<Stage path="bubble/buttons" label="Replies as buttons" />

## Reactions

`BubbleReactions` lays emoji or small buttons over the Bubble's edge: `side` the top or the foot, `align` the start or the end. A row of emoji is one picture (`role="img"`) with a name that reads it once. Leave room between rows for what overlaps.

<Stage path="bubble/reactions" label="Reactions" />

## Markdown

A short message reads framed; an answer in Markdown reads unframed, `ghost`, across the row.

<Stage path="bubble/markdown" label="Markdown" />
