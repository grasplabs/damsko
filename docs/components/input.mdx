## Basic usage

A FieldLabel above every field says what goes in. A placeholder only gives an example.

<Stage path="input/basic" live label="Basic usage" />

## Sizes

Button's heights: 36px, 32 in a dense table or toolbar, 44 for the one field that matters on a phone.

<Stage path="input/sizes" label="Sizes" />

## States

Disabled says why near it, and read only can still be copied. An error says how to put it right.

<Stage path="input/field-states" label="States" />

## With an icon

An icon at the start when it says what goes in faster. A password shows and hides itself.

<Stage path="input/icons" label="With an icon" />

## Kinds of text

The type brings the right keyboard on a phone and the browser's own check. A long value scrolls inside.

<Stage path="input/kinds" label="Kinds of text" />

## Words a machine reads

`mono` sets the words in the system's mono face, a step smaller on the same lines, so the field keeps its height: a cron line in an Input, a JSON body in a Textarea. No colours; it is a field, not a code view.

<Stage path="textarea/mono" label="Words a machine reads" />

## A secret

`SecretInput` holds a key pasted once: masked, never offered to a password manager. Once saved it shows only its last four.

<Stage path="input/secret" label="A secret" />
