## A finished run

`Subagent` is a Trace with one row that opens. `SubagentHeader` is its line: the run, by its `name` ("Ran the research agent"). `SubagentContent` holds what opens: `SubagentTools`, a nested Trace with a `SubagentTool` line for each tool call, and what the subagent found.

<Stage path="subagent/basic" label="A finished run" />

## While it runs

With `status="running"` the line runs, and the content shows the tool calls so far. Add what it found once it finishes.

<Stage path="subagent/running" label="While it runs" />

## Details

The model stands after the name as a Badge (`model`), how long it ran as a `TraceDescription`. `SubagentInstructions` holds the task it was given, at the top; a tool call can open on what it printed; `SubagentOutput` shows the shape of what it returns.
