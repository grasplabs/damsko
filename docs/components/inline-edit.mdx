## Basic usage

A press on the words, Enter or F2 opens the field with the value chosen. Enter saves, Escape keeps the value as it was, and leaving the field saves too. The page keeps the value and changes it in `onSubmit`.

<Stage path="inline-edit/basic" label="Basic usage" />

## Saving takes a moment

When `onSubmit` returns a promise, the field waits, read only, and says that it works. If the promise rejects, the field stays open with the words typed and says that it could not save.

<Stage path="inline-edit/async" label="Saving takes a moment" />

## A value that is refused

`validate` returns the words that say why a value cannot be saved. The field stays open, marked wrong, and is described by them.

<Stage path="inline-edit/validation" label="A value that is refused" />

## Opened by the page

`editing` and `onEditingChange` keep whether it is open, so a Rename button or a menu item can open it. `children` is the read view, when it is more than the words: here the heading's own text.

<Stage path="inline-edit/controlled" label="Opened by the page" />

## Kept open by the page

A page that holds `editing` decides when the field closes: one that keeps it open, as here, has each Enter save and the field stay for the next value. A field that is open from the start takes no focus, so the page does not jump to it; one that opens later takes it.

<Stage path="inline-edit/kept-open" label="Kept open by the page" />

## In a popup

`variant="popup"` leaves the text where it stands and opens the field in a small popup beside it, for a title that renames without its field taking the title's room: a page's name in its bar, a panel's or a card's title. Use it wherever the text stands in a row of a fixed height (a bar, a panel's head): inline, the field takes the text's place and a line under it says "Working" or why a save failed, so the row grows by that line or cuts it off. A press, Enter or F2 on the text opens it, titled by `aria-label` ("Rename"), the field's words chosen. Enter or Save saves; Escape or Cancel keep the value, and so does a press outside; the focus goes back to the text. The rules are the field's own: the new value trimmed, an empty or unchanged one keeps the old, `maxLength` stops the typing at the caller's most. While a save works, Save waits and the popup stays; when it fails, the popup stays open with the words typed and says why: `errorText`, or the catalogue's words. Cancel and Save are the I18nProvider's `inlineEdit` words.
