## Basic usage

A PaginationRange, the items shown and the total, with the steps at the end of the row.

<Stage path="pagination/range" label="Basic usage" />

## The page

A PaginationPage between the steps for the page and the count, where the range would say too much.

<Stage path="pagination/page" label="The page" />

## Steps only

The steps alone where the list already says how much it holds.

<Stage path="pagination/arrows" label="Steps only" />

## Page numbers

PaginationContent's children as a function of the pages to show: a PaginationLink for each page near the current one and at the ends, a PaginationEllipsis for each gap. The current page says so.

<Stage path="pagination/numbers" label="Page numbers" />

## Loading and empty

`loading` while the next page comes. With no items, neither step moves. `unit` says what the items are called ("projects"); without it the range uses the I18nProvider's `pagination.unit` ("items").

<Stage path="pagination/states" label="Loading and empty" />

## As links

`getPageUrl` gives each page an address; read the page back from it and pass it as `page`. For a router's own link, give it to PaginationLink, PaginationPrevious or PaginationNext with `asChild`.

<Stage path="pagination/links" label="As links" />

The steps' own states, then the ends, loading and an empty list.

## When to use it

<Intent
  of="pagination"
  always={[
    "A long list shown a page at a time, under the list and at its width.",
    "A name with `aria-label` when a page has two.",
    "A PaginationRange where people need to know how much there is; a PaginationPage where the range would say too much.",
    "`getPageUrl` where each page is an address, so back, a reload and a new tab open it.",
  ]}
  never={[
    "A list that never holds more than one page.",
    "A table of many rows, which pages itself: use Data table.",
    "The steps of a task, not the pages of a list: use Stepper.",
    "Paging away from selected rows without saying they stay selected.",
    "Loading without `loading`: a second press would skip a page.",
  ]}
/>
