## Side by side

Each handle carries what it resizes in `aria-label`; `minSize` keeps a panel usable.

<Stage path="resizable/horizontal" label="Side by side" />

## Stacked

`orientation="vertical"` stacks the panels, with the handle across.

<Stage path="resizable/vertical" label="Stacked" />

## With a grip

`withHandle` draws a grip on the handle; a `collapsible` panel folds away with Enter or a double click.

<Stage path="resizable/grip" label="With a grip" />

## Every state

Keyboard focus is forced from the handle's own CSS; hover and dragging set the mark UI SDK puts on it.
