## Parts

Select holds the value; SelectTrigger and SelectValue draw the control, SelectContent the list. Write items as parts, or pass `items`.

<Stage path="select/parts" live label="Parts" />

## Sizes

Input's heights: 36px, 32 in a dense table or toolbar, 44 for the one choice that matters on a phone.

<Stage path="select/sizes" label="Sizes" />

## With a label

A FieldLabel names it, or `aria-label` when nothing is seen. The placeholder is a verb and the thing.

<Stage path="select/field" live label="With a label" />

## Groups

A group names a run of items, and a separator sets one apart. An item out of use is skipped.

<Stage path="select/groups" label="Groups" />

## As words

`variant="ghost"` reads as its words and a small chevron, with no box: a level beside a person in a share list ("Can use"), a choice inside a sentence. A ghost button's height and hover; the keys, the list and the items are the same.

<Stage path="select/text" label="As words" />

## On one line

In a narrow place a long value wraps. With `truncate` on the trigger it stays on one line and ends in an ellipsis, as Button's and Dropdown menu's do; the list shows it whole.

<Stage path="select/truncate" label="On one line" />

## States

Wrong, disabled with why, and read only, which shows its value but does not open.

<Stage path="select/invalid" label="States" />
