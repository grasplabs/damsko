## How it waits

`animation="wave"` (the default): a fine dot field with one wave of light across the whole page. `pulse`: the soft fill, breathing.

<Stage path="skeleton/looks" label="How it waits" />

## Shapes

`text` for words, `rectangular` for an image or a chart, `circular` for an avatar.

<Stage path="skeleton/shapes" label="Shapes" />

## Text

Each line as tall as the line of words it stands for (`size`: `sm`, `default`, `lg`); the last of a paragraph shorter.

<Stage path="skeleton/text" label="Text" />

## In a layout

Each placeholder stands where its part will be, at its size, beside the others.

<Stage path="skeleton/layout" label="In a layout" />

## Still

`animation={false}` keeps the soft fill still, for a long list.

<Stage path="skeleton/still" label="Still" />

## Every state

Each variant and text size in the wave, then in the pulse.
