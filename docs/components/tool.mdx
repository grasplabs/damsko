## A finished call

Built on [Trace](/components/trace): `Tool` is a Trace with one row that opens, `ToolHeader` its line. `ToolHeader` names the tool and says where the call stands; a press opens `ToolContent` on its `ToolInput` and `ToolOutput`, each a Code block named Input and Output.

<Stage path="tool/basic" label="A finished call" />

## Every state

`state` is the AI SDK tool part's: `input-streaming`, `input-available`, `approval-requested`, `approval-responded`, `output-available`, `output-error` and `output-denied`. Each sets the line's status: running while the input comes and the call works, waiting on an approval, failed on an error; the title says the call in the tense of its state. Every state shows as a Badge after the title, in its colour and with its mark: Pending, Running, Awaiting approval, Responded, Completed, Error and Denied. A screen reader hears the line's status, and the Badge's words for the states a status cannot say (Awaiting approval, Responded, Denied). A state this version does not know is a neutral Badge with its own name.
