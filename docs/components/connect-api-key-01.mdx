## Choose, paste, connect

The providers stand as tiles; the chosen one becomes a row with Change, then its key. A provider with `address` asks for its address first. A block: it installs as source, to edit.

<Stage path="connect-api-key-01/basic" label="Choose, paste, connect" />

## A refused key

`onConnect` throws an Error with the service's reason: it stands under the key, and the key is cleared, as a secret that did not work is not kept. Connect says Not connected for a moment, then takes the key put right.

## Once connected

`connected` holds the provider and its key's last four, never the key. The card shows them with where it runs, Replace key, and Disconnect in the row's menu, which asks first and names what is lost (`disconnectDetail`).
