## Basic usage

A FieldLabel names it. A first option with the value "" is its placeholder, a verb and the thing, muted while it is chosen. Closed it is Select's control to the pixel; open it is the system's own list: the wheel on a phone, the platform's menu on a computer.

<Stage path="native-select/basic" live label="Basic usage" />

## Beside other fields

The same fill, hairline, lift, corner, words and heights as Input and Select, so a form uses whichever fits each choice.

<Stage path="native-select/fields" label="Beside other fields" />

## Sizes

Input's heights: 36px, 32 in a dense table or toolbar, 44 for the one choice that matters on a phone.

<Stage path="native-select/sizes" label="Sizes" />

## Groups

NativeSelectOptGroup names a run of options; its name is never chosen. An option out of use is shown, greyed.

<Stage path="native-select/groups" label="Groups" />

## In a form

It is a `<select>`: sent under its Field's `name`, held back by `required` until a value other than "" is chosen, with its FieldError under it, and back to its first value on a reset.

<Stage path="native-select/form" live label="In a form" />

## When to use it

<Intent
  of="native-select"
  always={[
    "A form that posts as it is, or code and tests that set a select's own value.",
    "A long list on a phone, where the system's wheel is the easiest way to choose.",
    "Choices that are words alone: the system's list draws no icon, description or second line.",
    'A first option with the value "" and a verb and the thing as its placeholder: Choose a channel.',

  never={[
    "Choices that need more than words, a ghost look, or an agent that chooses by name: use Select.",
