## Unified

Each removed line over the one that replaced it; the words that changed are marked a step deeper. Every line says Added or Removed to a screen reader, as well as its colour and its plus or minus.

<Stage path="diff-viewer/unified" label="Unified" />

## Side by side

Before on the left, after on the right, for a wide screen.

<Stage path="diff-viewer/split" label="Side by side" />

## Switching the view

`mode` is the page's to switch: here a ToggleGroup between unified and side by side.

<Stage path="diff-viewer/view" label="Switching the view" />

## Hunks and whole lines

For code read by people who know patches: `showHunkHeaders` puts a hunk's header, `@@ -12,7 +12,8 @@` as git writes it, before each run of lines, and `wrap={false}` keeps each line whole, the lines scrolling sideways inside the diff, never the page.

<Stage path="diff-viewer/hunks" label="Hunks and whole lines" />

## Review

Accept or reject each change of an edit: it is taken at once, the row stays put, and Undo puts it back. `onDecisionChange` hears each.

<Stage path="diff-viewer/review" label="Review" />

## Prose

`mode="inline"`: what was taken out is struck through, what was put in is underlined.

<Stage path="diff-viewer/prose" label="Prose" />

## A long file

Unchanged stretches fold away; past `virtualizeThreshold` rows a long diff draws only the lines in view.

<Stage path="diff-viewer/long" label="A long file" />

## Several files

`DiffViewerFiles`: each file under its own header, the folder quiet, the file's name strong, Added, Deleted or Modified in a Badge, and its lines added and removed. A file with no `oldValue` is new; one with no `newValue` is deleted. Its lines are DiffViewer's, unified, with a hunk's header before each run and long lines kept whole.

<Stage path="diff-viewer/basic" label="Several files" />

## A big file

A file with more changed lines than `foldFrom` opens folded, so it does not bury the rest; its header, a Collapsible's trigger, opens it.

<Stage path="diff-viewer/folded" label="A big file" />

## When to use it

<Intent
  of="diff-viewer"
  always={[
    "What changed in a file or a document, before and after; a person answering an edit, change by change.",
    "A title that names the file or the document.",
    "Several files in the order the person reads them: what they asked for first.",
  ]}
  never={[
    "Code to read or copy, with nothing changed: use Code block.",
    "A value that changed: say the old and the new in words, with Text.",
    "Colour alone for added and removed: the marks, the words and the strike stay.",
  ]}
/>
