## Variants

`default` for a quiet head, `tinted` for a wash of mint, `gradient` for the one object a view is about.

<Stage path="icon-tile/looks" label="Variants" />

## Loading

With `loading`, while the object works, the light leans down once and stays until it stops. Say it in words too.

<Stage path="icon-tile/running" label="Loading" />

## In a table's row

`size="sm"`: a 24px tile for an object in a dense row. Give its column `control`, and a compact row stays 32px, a default one 42px, as a row of words alone. That cell is one line tall: keep the name beside the tile on one line, ending in an ellipsis where it is narrow.

<Stage path="icon-tile/row" label="In a table's row" />
