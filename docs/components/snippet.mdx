## Basic usage

An install command, the way it stands at the top of every page here. A press anywhere on it copies it.

<Stage path="snippet/basic" label="Basic usage" />

## Colours

`swatch` puts the colour before its name, for a list of tokens. `size="sm"` for a list.

<Stage path="snippet/colours" label="Colours" />

## Sizes

`sm` 28px for a list of values, `default` 32px for one value on its own.

<Stage path="snippet/sizes" label="Sizes" />

## A long value

Narrower than its value, the field scrolls sideways and fades the end with more. It never breaks the value and never cuts it short.

<Stage path="snippet/long" label="A long value" />

## When to use it

<Intent
  of="snippet"
  always={[
    "A value someone copies to use elsewhere: an install command, an id, a key, a token's name or value.",
    "Show the whole value: what is copied is what is seen.",
    "Name the button for what it copies: Copy the install command.",
  ]}
  never={[
    "Code of more than one line, or code to read: use Code block.",
    "A fact with its name, where copying is a side action: use Key value.",
    "Something larger than what it shows (a message, a page): use Copy button.",
  ]}
/>
