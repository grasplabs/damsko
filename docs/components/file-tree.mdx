## The files changed

Folders open and close; a press, Enter or Space on a file chooses it. A press on a folder opens or closes it and never chooses it. A letter finds the next file or folder.

<Stage path="file-tree/basic" label="The files changed" />

## An icon for each kind of file

Each file wears an icon for its extension: a document, a sheet, an image, a video, a sound, code, or the plain file for one it does not know. `icon` gives a file its own.

<Stage path="file-tree/icons" label="An icon for each kind of file" />

## Buttons on a row

`FileTreeActions` holds a row's buttons at its end. Pressing one, or a key on one, runs it and leaves the row as it was: the chosen file stays chosen. Here the page holds the chosen file with `selectedPath` and `onSelect`.

<Stage path="file-tree/actions" label="Buttons on a row" />
