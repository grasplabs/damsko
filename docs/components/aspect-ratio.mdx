## Ratios

`ratio` is width over height; what it holds fills it at width and height 100%.

<Stage path="aspect-ratio/ratios" label="Ratios" />

## Flush in a frame

`rounded={false}` when the frame around it cuts the corner.

<Stage path="aspect-ratio/flush" label="Flush in a frame" />

## Every state

It has no states of its own, so the row shows its common ratios, and flush.
