## Basic usage

Given `onUpload`, each file is sent as it arrives and shows how far it is; a failed one has Try again. What it takes (`accept`, `maxFileSize`, `maxFiles`) is checked as each file arrives, and one it refuses is named with the reason, under the dropzone and to a screen reader. `description` says what it takes, in words, under the dropzone; without it, the kinds of file and the largest size are said in the I18nProvider's words (`fileUpload.limits`).

## One file, with the form

Without `onUpload` the files go with the form. Without `multiple`, a new file takes the old one's place. Without script it is a plain file field.

<Stage path="file-upload/single" label="One file, with the form" />

## Rows that carry on, and a button form

`getFileStatus` says on a file's row what the host is doing; `getFileActions` adds Open and Download. `variant="button"` and `listContainer` part the button from the list.
