## Words

A prefix, a suffix or a unit beside what is typed, in an `InputGroupAddon`: `align="inline-start"` before the input, `"inline-end"` after it. It is shown, never sent, and a press on it puts the caret in the input.

<Stage path="input-group/text" label="Words" />

## Search

An icon says what goes in, and a clear button shows once there is text.

<Stage path="input-group/search" label="Search" />

## With a button

An `InputGroupButton` in an addon acts on what the field holds: a ghost Button, small, set in from the edge by the same room on every side. Icon only, it takes an `aria-label`.

<Stage path="input-group/button" label="With a button" />

## Several lines

`InputGroupTextarea` grows with its text; an addon with `align="block-end"` stands under it, across the group, and `"block-start"` over it.

<Stage path="input-group/textarea" label="Several lines" />

## Sizes

Input's heights: 36px, or 44px where a form has room.

<Stage path="input-group/sizes" label="Sizes" />

## Small, in a settings row

`size="sm"` is Input's 32px: a field that holds a badge stands level with a plain small Input beside it, with the same words.

<Stage path="input-group/small" label="Small, in a settings row" />

## Every state

The group shows its input's state round all its parts. Hover, keyboard focus and pressed are forced from its CSS; the rest are props.

## When to use it

<Intent
  of="input-group"
  always={[
    "Words that help read the value: a prefix, a unit, a domain.",
    "One button that acts on what the field holds: Copy, Send.",
    "A label on the field: the words inside the edge are not its name.",
  ]}
  never={[
    "A label or a sentence inside the edge.",
    "More than one button: put the rest beside the field.",
    "A field with nothing inside its edge: use Input.",
    "Colours, heights or corners set from outside: `style` takes layout and width only.",
  ]}
/>
