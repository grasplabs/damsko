## Basic

Each step links up the path, a BreadcrumbSeparator between them; the last is the page you are on.

<Stage path="breadcrumb/basic" label="Basic" />

## Long path

A BreadcrumbEllipsis holds the levels between the first and the parent: a "…" that opens them in a menu, as links, in the path's order. The "…" is an icon-only Button: under a resting pointer and on keyboard focus its tooltip shows its name.

<Stage path="breadcrumb/long" label="Long path" />

## Long page name

When the line has no room left, the page's name is cut off, down to a few letters; it then takes keyboard focus, and its tooltip shows it whole.

<Stage path="breadcrumb/long-page" label="Long page name" />

## On a phone

Under 640px only the parent stays, as a back link; `variant="back"` keeps that form at any width.

<Stage path="breadcrumb/phone" label="On a phone" />

<Part title="Using it" />

## A path with no links

A step without `href` is its name alone. Only a `BreadcrumbPage` is the page you are on; a file's path has none, and its last step, where the path ends, is drawn in the ink.

<Stage path="breadcrumb/path" label="A path with no links" />

## A trail that acts in place

A step that reopens a folder in place is a button, given as the child with `asChild`; so is a router's link. It keeps a link's look, focus and hover. When the step pressed becomes the page, focus moves to the page.

<Stage path="breadcrumb/folders" label="A trail that acts in place" />
