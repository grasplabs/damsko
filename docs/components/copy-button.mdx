## Copy

Icon only by default, named by `aria-label` and with a tooltip that says it. With words as its children it shows them beside the icon. Once copied the check shows for a moment, and a screen reader hears it once.

<Stage path="copy-button/basic" live label="Copy" />

## When it copies

A `value` that is a function is read at the press, so it copies what is there then. `onCopy` runs with what was copied, once it is on the clipboard: not when the copy failed, and not for a press while the result still shows.
