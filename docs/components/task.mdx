## A finished task

`Task` is a Trace with one row that opens. `TaskTrigger` is its line, the task's `title`; it starts open on `TaskContent`, the steps it took, each a `TaskItem` with its mark. A file a step names is a `TaskItemFile` chip.

<Stage path="task/basic" label="A finished task" />

## While it runs

Each step arrives when the assistant takes it, running until it is done. The task's title is in the present tense while a step runs and in the past once all are done; then it closes. A step or a task that finishes is said once. Press Next to finish the running step.

## When to use it

<Intent
  of="task"
  always={[
    "Work whose steps come from the work itself: the assistant knows the next step only once it has taken the last.",
    "A title in the tense of its status: Updating the page metadata while a step runs, Updated the page metadata once done, Failed to update the page metadata when a step failed.",
    "Several tasks one under another, the running one open, each closing once it is done.",
  ]}
  never={[
    "Steps decided before the work starts, some still waiting: use Plan.",
    "The steps of one answer, each with what it found, folded into the run's summary: use Chain of thought.",
    "One call to a tool, with its input and output: use Tool.",
  ]}
/>
