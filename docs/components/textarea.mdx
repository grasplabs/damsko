## Basic usage

A FieldLabel above it says what goes in. It grows with its text, then scrolls.

<Stage path="textarea/field" live label="Basic usage" />

## States

Wrong, disabled with why, and read only, which can still be copied.

<Stage path="textarea/field-states" label="States" />

## A limit

`maxLength` stops the text at the limit, and the description counts towards it.

<Stage path="textarea/count" label="A limit" />

## Sending with the keyboard

With `submitShortcut`, Cmd or Ctrl+Enter sends the form. Press it while empty to see the error.

<Stage path="textarea/invalid" label="Sending with the keyboard" />

## Words a machine reads

`mono` sets the words in the system's mono face, a step smaller on the same lines, so the field keeps its height: a cron line in an Input, a JSON body in a Textarea. No colours; it is a field, not a code view.

<Stage path="textarea/mono" label="Words a machine reads" />
